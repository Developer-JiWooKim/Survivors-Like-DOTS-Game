B-1. 세션 시작 절차

B-2. 기록 (두 문서로 분리, 계속 누적)
  - WorkLog: 날짜별 작업 내용. 날짜+마일스톤, 무엇을 했나, 왜(대안/포기
    이유/트레이드오프), 성능 수치(before/after, 조건), 배운 것, 커밋 해시.
    작업 마칠 때 상단 "📍 현재 위치" 블록을 반드시 갱신.
  - IssueLog: ISSUE-00X 순번(재사용 금지). 발생 시점에 먼저 ⏳진행중으로
    등록하고 해결되면 갱신. 증상(에러 원문), 재현 조건, 원인,
    "시도한 것과 각각의 결과(실패 포함)", 해결/재발 방지, 해결일.
    상단 이슈 목록 표를 항상 최신으로.
  - 두 문서는 이슈 ID 로 상호 참조.
  - 기준: 면접에서 "왜 이렇게 했어요?" 에 이 문서만 읽고 답할 수 있게.
    실패하고 되돌린 시도가 가장 가치 있다.

[D] 이전 프로젝트 배경 (참고용 요약)
--------------------------------------------------------------------------
D-1. 결과
  - Unity 6 DOTS 2D 뱀서라이크 기능 프로토타입. M0~M3 완료 + 빌드 실측.
  - 적 10,000 @ 릴리스 빌드 460~480 FPS (≈2.1 ms), 지형 시뮬 + 무기 3종
    전부 켠 조건. i7-10700 · GTX 1660 · 1920×1080 · Mono.
    에디터 약 240 FPS. 병목은 CPU 메인 스레드.
  - IL2CPP 재측정은 하지 못했다 (모듈 미설치).
  - 이 확장판(3D 우주 슈터)은 원래 "M4 이후는 별도 저장소에서" 하기로 한
    결정의 연장이다.

D-2. 재사용 후보 DOTS 구조 (3D 에 맞는지는 새로 판단)
  - enableable 풀링: 생성/파괴 대신 Enabled 토글 + MaterialMeshInfo 토글.
    구조적 변경 0. 무기 획득도 enableable. (적 20,000 / 젬 4,000 /
    투사체 512 풀)
  - 공간 해시: NativeParallelMultiHashMap, 셀 1.0. 분리·충돌 조회.
    → 3D 면 셀을 2D(평면)로 둘지 3D 로 둘지 결정 필요.
  - NativeStream 피해 버스: 병렬 잡이 피해 이벤트를 쓰고 한 곳에서 드레인.
  - 지형 효과 큐, 10Hz 더블 버퍼 시뮬레이션, 결정적 해시 난수
    ((타일 인덱스 + 틱) 해시).
  - 흐름장(아이코널 거리 필드)으로 적 경로 — 3D 에서 필요한지 재검토.
  - 리사이클: 플레이어에서 일정 거리 이탈한 적을 반대편 링으로 재배치.
  - 벤치마크 모드: 고정 목표 수, 무적, 레벨업 없음.

D-3. 겪은 함정 (새 프로젝트에서 미리 피할 것)
  - 빌드는 마지막에 처음 돌리지 말고 초반부터 주기적으로 돌릴 것.

  - SSAO 가 DepthNormal 프리패스로 지오메트리를 2배 제출 (ISSUE-005).
    렌더러 기능을 "끄기만" 하면 빌드에서 리소스가 스트리핑되어
    파이프라인 생성 실패 → 검은 화면 (ISSUE-018). 안 쓸 기능은 제거.
  - 잡 완료 전에 메인 스레드가 컴포넌트를 읽으면 예외 대량 발생

  - 격자 거리 척도로 흐름장 경로가 계단형 (ISSUE-014) → 아이코널.
